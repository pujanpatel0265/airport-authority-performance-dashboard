# Airport Authority Performance Dashboard

## Project Overview
This project analyses airport authority performance using Power BI. The dashboard focuses on key operational areas such as total flights, delayed flights, average ground time, cancellation rate, on-time performance, monthly reliability, and delay impact by airline and origin.

The main purpose of this project is to help airport management understand flight performance and identify delay patterns for better operational decision-making.

## Tools and Technologies
- Power BI
- Data Visualisation
- Business Intelligence
- Dashboard Design
- Airport Operations Analysis

## Dashboard Features
- Total flights KPI
- Total delays KPI
- Average ground time KPI
- Percentage of delayed flights
- Cancellation rate
- On-time performance
- Monthly service reliability
- Delay impact by airline
- Delay impact by origin
- Flight trend by month
- Origin and destination filters
- Geographic flight map

## Key Insights
- A significant number of flights were affected by delays.
- Ground time is an important factor in flight schedule performance.
- On-time performance helps measure airport and airline efficiency.
- Some airlines and origins show higher delay impact than others.
- Monthly trends help identify seasonal changes in flight operations.
- Geographic visualisation helps understand flight distribution and route concentration.

## Business Value
This dashboard can help airport stakeholders:
- Monitor flight operations
- Identify delay patterns
- Improve resource planning
- Track airport and airline performance
- Support data-driven decision-making
